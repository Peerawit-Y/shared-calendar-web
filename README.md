# ปฏิทินส่งงาน & สอบส่วนกลาง (Shared Calendar Web App)

เว็บแอปพลิเคชันปฏิทินส่วนกลางสำหรับติดตามกำหนดส่งงาน การบ้าน และวันสอบร่วมกับกลุ่มเพื่อน เชื่อมต่อกับ **Google Sheets** เป็นฐานข้อมูลผ่าน **SheetDB** รองรับการตั้งค่าผ่านไฟล์ `.env` และรันด้วย `npm run dev`

---

## ฟีเจอร์หลัก
- 📅 **มุมมองปฏิทิน (FullCalendar):** ดูภาพรวมรายเดือน สัปดาห์ หรือรายการ
- 🎓 **แบ่งตามเทอม (Semester Filter):** กรองดูเฉพาะเทอมที่ต้องการได้ เช่น `1/2569`, `2/2569`
- 🏷️ **แยกสีตามประเภทงาน:** สอบ (สีแดง), การบ้าน (สีส้ม), โปรเจกต์ (สีม่วง), นัดหมาย (สีฟ้า)
- ⏳ **นับถอยหลัง D-Day:** คำนวณวันคงเหลือให้อัตโนมัติ (เช่น วันนี้!, อีก 3 วัน, เลยกำหนด)
- ➕ **ฟอร์มเพิ่มงานใหม่:** บันทึกข้อมูลลง Google Sheet แบบ Real-time
- 🔐 **ตั้งค่าผ่าน `.env`:** ใส่ URL ครั้งเดียวใน `.env` ไม่ต้องกรอกซ้ำ

---

## ขั้นตอนการติดตั้งและเชื่อมต่อ Google Sheet

### 1. เตรียม Google Sheet
1. สร้าง Google Sheet ใหม่
2. ตั้งชื่อหัวคอลัมน์ใน **แถวที่ 1** ดังนี้:
   ```text
   term, subject, title, type, due_date, status, link
   ```

### 2. สร้าง API ด้วย SheetDB
1. เข้าไปที่ [https://sheetdb.io](https://sheetdb.io) แล้วเข้าสู่ระบบด้วย Google
2. กด **Create new API** และนำ URL ของ Google Sheet ด้านบนมาวาง
3. คุณจะได้รับลิงก์ API เช่น:
   `https://sheetdb.io/api/v1/xxxxxxxxxxxx`

### 3. ใส่ URL ในไฟล์ `.env`
เปิดไฟล์ `.env` แล้ววางลิงก์ที่ได้:
```env
VITE_SHEETDB_API_URL=https://sheetdb.io/api/v1/xxxxxxxxxxxx
```

## คำสั่งเปิดใช้งาน (Development)

```bash
# รันโปรเจกต์
npm run dev

# บิลด์สำหรับ Production
npm run build
```
เมื่อรัน `npm run dev` ให้เปิดเบราว์เซอร์ไปที่ลิงก์ที่แสดงใน Terminal (เช่น `http://localhost:5173`)
